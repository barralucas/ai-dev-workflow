## Como escrever uma user story

```
US-XXX — <título curto e acionável>
Como <ator>,
quero <capacidade>,
para que <benefício / valor>.

Critérios de aceite (Gherkin opcional):
  - Dado <contexto>, quando <ação>, então <resultado>.
  - ...

Notas técnicas:
  - <restrição / dependência / risco>

Estimativa: P / M / G
Prioridade: must | should | could | won't (MoSCoW)
```
