# Changelog

Todas as mudanças relevantes deste workflow são documentadas aqui.

Formato baseado em [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) e versionamento semântico.

## [0.1.0] — 2026-05-05

### Added

- Núcleo do workflow em 7 fases (`workflow.instructions.md`).
- Instruções de qualidade, segurança (OWASP), testes, git e documentação.
- Adendos de stack: Next.js, Node backend, Python, mobile.
- Templates de `PROGRESS.md`, ADR, feature doc, user-stories backlog.
- Templates de risk register, postmortem e spike (lacunas em relação ao projeto-base).
- Prompts reutilizáveis: `new-feature`, `bug-fix`, `refactor`, `adr`, `code-review`, `postmortem`, `onboard-agent`.
- Chat mode "architect" (read-only + ADR).
- Script `bootstrap.sh` para inicializar projetos novos.
- Documentação do próprio workflow (`getting-started`, `customizing-for-your-stack`, `glossary`, `faq`).

### Notas

- Primeira versão pública. API de instruções/templates pode mudar até `1.0.0`.
